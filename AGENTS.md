Računi is a React Native Android app: it scans fiscal receipt QR codes and saves each receipt as a PDF to Google Drive.

## Layout

- `App.js`: the UI (onboarding, scanner, receipt list) and the update check.
- `receipt.js`: parses the receipt URL and page; tested by `receipt.test.mjs`.
- `drive.js`: Google Drive REST calls.
- `version.js`: the app version (CI replaces it with `1.0.<build>`) and the release URL.
- `app.config.js`: the app name, package, icons, permissions and native plugins.

## Rules

- `android/` and `ios/` are generated by `npx expo prebuild` and are not committed. Never create or edit them by hand; put native settings in `app.config.js`.
- Add native packages with `npx expo install <package>` so the versions match the installed SDK, and check the docs for that SDK's major version (see `package.json`), not memory.
- Run `node receipt.test.mjs` before declaring a change done.
- Every push to `main` builds, signs and publishes a release (`.github/workflows/build.yml`).
